## Recommended SVG Naming Convention

Use Unicode codepoint hex format (Twemoji standard):
```
Single emoji:    1f344.svg  (🍄)
Multi-codepoint: 1f468-200d-1f4bb.svg  (👨‍💻)
Variation:       2600-fe0f.svg  (☀️)
```

Example Python converter:
```python
def emoji_to_filename(emoji: str) -> str:
    codepoints = [f"{ord(c):x}" for c in emoji]
    return "-".join(codepoints) + ".svg"
```
