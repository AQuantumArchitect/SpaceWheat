## 🎯 Purpose

While gameplay emojis (🌾🍄🐺) represent in-game content, **functional emojis** provide:
- **Visual feedback** (progress bars, status colors)
- **UI elements** (buttons, indicators, controls)
- **Mathematical notation** (operators for quantum calculations)
- **Debug/dev tools** (color coding for testing)

Think of these as **UI toolkit emojis** rather than game content.

### Progress Visualization
```gdscript
func render_buffer_bar(depth: int, max_depth: int) -> String:
    var bars = ["▁", "▂", "▃", "▄", "▅", "▆", "▇", "█"]
    var fill_ratio = float(depth) / float(max_depth)
    var bar_index = int(fill_ratio * 7)
    return bars[bar_index]
```

### Math Expression Builder
```gdscript
func format_craft_recipe(input: Dictionary, output: Dictionary) -> String:
    var parts = []
    for emoji in input.keys():
        parts.append("%d%s" % [input[emoji], emoji])
    var inputs = " ➕ ".join(parts)

    var outputs = []
    for emoji in output.keys():
        outputs.append("%d%s" % [output[emoji], emoji])
    var result = " ➕ ".join(outputs)

    return "%s 🟰 %s" % [inputs, result]
    # Output: "10🌾 ➕ 5💧 🟰 3🍞"
```
