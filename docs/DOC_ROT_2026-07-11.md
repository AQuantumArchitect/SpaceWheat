# Doc Rot Audit — 2026-07-11

A fresh-eyes pass over ~90 project docs (the ~113 `.md` files in the tree minus
vendored dirs and the 🍄/ playzone internals) ahead of the itch.io soft launch.
This doc records the verdicts and what was done, so the reasoning survives the
moves.

**Headline:** the doc tree is healthier than feared. The July-2026
closed-system stratum — `Core/Documentation/glossary/`, `HOW_TO_PLAY.md`, `GAME_CODEX.md`,
`CLOSED_SYSTEM.md`, `KEYBOARD_GRAMMAR.md`, `README.md`, `FOR_PHYSICISTS.md` —
is current and *self-correcting* (it documents its own retirements). The rot
concentrated in one stratum: the **December-2025 `docs/reference/` +
`docs/architecture/` cluster**, plus half-migrated "vocabulary" stragglers and
the `llm_inbox/`/`llm_outbox/` handoff correspondence.

The most dangerous instance: `GAME_CODEX.md` §10 ("Canonical docs") listed the
dead December cluster as canon, and `GAMEPLAY_BELL_GATE_ACTION.md` wore a
"✅ FULLY TESTED — 20/20 Operations Passing" banner over a mechanic that no
longer exists. Confident status banners on deleted systems are the rot that
actually bites.

## ARCHIVED (moved to `archive/`)

Per `archive/README.md`: historical only, nothing here is runtime truth.
Note `archive/` is **gitignored** (the repo's convention: archived docs leave
the repo; the dir is a local graveyard). Repo-side these moves are deletions —
recoverable from git history; the files live on locally under `archive/`.

- `docs/reference/` (all 4) → `archive/docs/reference/`
  - `GAMEPLAY_BELL_GATE_ACTION.md` — describes the deleted "kitchen
    measurement" triplet mechanic (`mark 3 plots as a kitchen measurement
    target`, `biome.mark_bell_gate`). Bell/GHZ gates now live on the Operator
    hat (9). The "20/20 passing" banner refers to tests that predate the
    redesign.
  - `BUBBLE_CLICKS_AND_PLOT_ENTANGLEMENT.md`, `BERRY_PHASE_SYSTEM.md`,
    `FORCE_GRAPH_ENHANCEMENT.md` — frozen at the 2025-12-23 commit; predate
    the closed-system migration, the hat system, QERF, and the glossary.
    (Berry phase itself is live canon — see `Core/Documentation/glossary/berry.md`; only
    this implementation doc was stale.)
- `docs/architecture/EMOJI_TOPOLOGY_LANGUAGE.md`,
  `docs/architecture/BIOME_BELL_GATES_ARCHITECTURE.md` → `archive/docs/architecture/`
  — same dead stratum; the emoji-relationship-graph model was superseded by
  icon/signature/cloud.
- `docs/BOAT_CRISIS_QUEST_ARC.md` → `archive/docs/` — pre-unification quest
  framing; superseded by `docs/QUEST_SYSTEM_PLAN.md` + the contract market.
- `docs/inspiration/VOCABULARY_GATING.md` → `archive/docs/inspiration/` —
  body still taught the retired atom-overlap faction gate; canon is
  `Core/Documentation/glossary/faction.md` + `Core/Documentation/glossary/signature.md` (signature =
  icon-pair ownership).
- `llm_inbox/`, `llm_outbox/` — **left where they are**: both trees turned
  out to be gitignored already (98 files on disk, zero tracked), i.e. local
  correspondence invisible to the repo. Moving them into the tracked
  `archive/` would have *added* the stale content. Treat them as archival in
  place; the contract-market and icon-registry bundles describe now-shipped
  systems and use retired "vocabulary" as live canon.
