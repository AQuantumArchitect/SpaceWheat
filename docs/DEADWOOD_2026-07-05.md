# Deadwood census — 2026-07-05

Static dead-code audit of `Core/`, `UI/`, `Rig/` (three parallel sweeps:
duplication, dead code, debug slop). Everything listed here has **zero
GDScript call sites repo-wide** — verified against bare identifiers, quoted
names (`has_method` / `call()` / signal-by-name dynamic dispatch), and
`tests/` as a consumer. It was **not deleted** in the same sweep that
produced it, on purpose: bulk-culling public API without a runtime pass is
gambling, and several clusters read as intentional library surface. This
census is the work order for a verified cull (testing bots, or any session
with a Godot binary: delete a cluster, boot, run the suites, keep or revert).

**Already culled in the sweep** (verified individually, commits of
2026-07-05): the four broken root scenes (missing scripts), orphan files
`EmojiSequenceGenerator.gd` + `PanelTouchButton.gd`,
`FactionStateMatcher.generate_quest_parameters` + `QuestParameters` +
`_get_basis_weights`, `AlignmentGraph.from_maximally_mixed`,
`QuestManager.print_quest_status` + `test_quest_lifecycle`,
`rig_listener.bridge_idle` signal, and IconRegistry's eleven superseded
accessors (callers migrated to the `*_record` API long ago).
