# Vocabulary Gating — Organic Faction Tech Tree

No artificial locks. Faction access emerges from emoji vocabulary overlap.
A player who knows certain emojis can access certain factions — naturally.

## The Mechanism

Each faction has a **signature vocabulary** (4-5 thematic emojis).
A player can access a faction only if their known-icons set contains
at least one emoji from that faction's signature.

No menu. No unlock screen. Just overlap math.

## Gateway Emojis

Some emojis unlock the most factions — natural chokepoints and hubs:

| Emoji | Factions Unlocked | Branch |
|---|---|---|
| 💰 gold | ~8 factions | Commerce hub |
| ⚔ sword | ~7 factions | Military branch |
| 📡 satellite | ~7 factions | Tech branch |
| 🍞 bread | ~5 factions | Agrarian + mystical |
| 🌱 seedling | ~5 factions | Production chain root |

## Natural Progression Branches

Players follow different routes based on what they learn first:

**Agricultural → Commercial → Industrial:**
🍞 → 🌱 → 💰 → ⚙

**Social → Documentation → Logistics:**
👥 → 📋 → 🚢

**Bread → Fermentation → Religion → Alchemy:**
🍞 → 🥖 → ⛪ → 🧪

**Parts → Factories → Labs:**
⚙ → 🔩 → 🏭 → 🔬

These branches are not programmed — they emerge from the emoji overlap graph.

## Quest Vocabulary Should Use Signature Only

**Critical design rule:** Quest resources should sample from the *faction's signature*,
not from starter vocabulary or axial vocabulary. Otherwise all factions request
the same starter emojis (e.g., everyone asks for wheat 🌾).

Starter vocab: 🍞 👥 (bread, people)
Each faction's quest requests: their own 4-5 signature emojis

Result: Every faction feels distinct. No explicit differentiation code needed.
